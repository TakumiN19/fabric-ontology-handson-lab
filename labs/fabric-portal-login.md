# Microsoft Fabric ポータルへのサインイン（初回のみ）

このガイドでは、ハンズオン用のアカウント（例: `student01@M365x43914722.onmicrosoft.com`）で **Microsoft Fabric ポータル**（`https://app.fabric.microsoft.com`）へ初めてサインインする手順を説明します。

普段お使いの社内 Microsoft 365 アカウントと混ざらないよう、**必ずブラウザのゲストプロファイルまたはシークレット／InPrivate ウィンドウ**を使って開いてください。

---

## 1. シークレット / InPrivate ウィンドウを開く

- **Microsoft Edge**: `Ctrl + Shift + N`（macOS は `⌘ + Shift + N`）
- **Google Chrome**: `Ctrl + Shift + N`（macOS は `⌘ + Shift + N`）

## 2. Fabric ポータルへアクセスしてサインインする

1. アドレスバーに `https://app.fabric.microsoft.com` を入力して開きます。
2. 配布されたアカウント（`student<番号>@M365x43914722.onmicrosoft.com`、または講師指定のアカウント）とパスワードでサインインします。
3. 初回サインイン時に多要素認証（Microsoft Authenticator 等）のセットアップを求められた場合は、画面の案内に従って登録を完了します。

## 3. 自分のワークスペースを確認する

1. 左ナビゲーションの **Workspaces（ワークスペース）** をクリックします。
2. 自分の `student<番号>` ワークスペース（例: `student01`）が表示され、名前の横に **ダイヤのアイコン（Fabric 容量割り当て済み）** が付いていることを確認します。
3. ワークスペースを開いた状態でブラウザのタブを残しておくと、Lab 03〜Lab 07 での Ontology キャンバス・Graph ビュー・Data Agent・Microsoft Foundry ポータル確認がスムーズに進みます。

---

確認できたら、[Lab 00](./00-prerequisites.md) または [Lab 01](./01-login-and-data-setup.md) に戻って進めてください。
